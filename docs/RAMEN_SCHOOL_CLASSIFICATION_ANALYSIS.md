# 拉麵派系客觀分類可行性分析

> 對日本與台灣拉麵派系，採用 MBTI（16 型）/ 九宮格（9 型）等模式進行**不依賴主觀感受**之分類的可行性研究。
>
> 本文不修改任何程式碼，純為架構決策分析文件。

---

## 第 0 章 · TL;DR（一頁速覽）

### 一句話結論
- **MBTI 16 型（4 軸二元）** 在拉麵領域 **可行但不正交、會產生大量空格與重疊**，較適合作「偏好風格描述」、不適合「身分歸屬分類」。
- **3×3 九宮格（蛋白家族 × 湯體狀態）** **可行且最乾淨**，幾乎沒有空格，是「身分分類」的最佳起點。
- **Enneagram-9（九型人格）** 不適合：其哲學基礎是「動機論」，在拉麵領域無對應。
- **客觀分類的關鍵**：用「**可觀測 / 可量測 / 可考證的事實**」當主軸，而非「吃起來的感受」。

### 三大客觀軸（推薦）
1. **主蛋白來源 (Main Protein Lineage)** — 食材清單可考
2. **湯體乳化狀態 (Broth Emulsification State)** — 濁度計可量、目視可辨
3. **調味基底 (Tare Type)** — 配方可考（醬油 / 鹽 / 味噌）

再以 **地域、流派血統、麵條規格、必有配料組合** 作為可多重的輔助標籤。

## 第 1 章 · 為什麼分類拉麵是個難題

### 1.1 拉麵不是單一維度的料理
拉麵是 **湯 × 麵 × 油 × 調味 × 配料 × 烹調手法 × 地域** 六到七個半獨立維度的組合。任何單軸分類都會丟資訊。

### 1.2 既有分類體系的並存與衝突
四種命名邏輯交叉並存，沒有任一個是完整的：

| 命名邏輯 | 範例 | 特性 |
|---|---|---|
| **地域命名** | 博多、札幌、喜多方、東京、橫濱、京都 | 隱含一組典型配方但**不互斥**（橫濱也可開博多風） |
| **流派命名** | 家系、二郎系、AFURI 系、一風堂系 | **血統傳承式**，與地域交叉 |
| **技法命名** | 清湯、白湯、つけ麺、油そば、二郎風 | 描述**製程或湯體狀態** |
| **食材命名** | 豚骨、雞白湯、魚介、貝、鴨、牛、蝦 | 描述**主蛋白來源** |

同一碗常同時屬於多個分類：例如「博多豚骨醬油系細麵」= 地域 + 食材 + 調味 + 麵條規格。

### 1.3 使用者明確排除的方向：純感受形容詞
「甜 / 酸 / 苦 / 辣 / 鹹」這類純味覺感受詞 **不適合作分類**，因為：
- **缺乏可考證標準**：沒有客觀「鹹度單位」對應使用者感受。
- **個人閾值差異大**：同一碗在 A 眼裡很鹹、在 B 眼裡剛好。
- **無血統 / 製程支撐**：感受詞不能定義「這是家系」。

### 1.4 核心區分：身分屬性 vs 描述屬性
- **身分屬性（Identity）**：血統、製程、可考證事實 → 適合**互斥分類**。
- **描述屬性（Descriptive）**：感受、偏好強度 → 適合**評分推薦**。

本文聚焦前者。

## 第 2 章 · 客觀（非主觀）分類維度盤點

這是回答 Q3 的核心。把所有「可觀測 / 可量測 / 可考證」的維度列出，並標示客觀程度。

### 2.1 食材血統維度（Ingredient Lineage）
- **主蛋白來源**（豚 / 雞 / 牛 / 鴨 / 魚介 / 貝 / 蝦）— **客觀程度：極高**（食材清單直讀）
- **副蛋白與比例**（雞豚混、雞魚介 W スープ 等）— **客觀程度：高**
- **是否含 V 系**（蔬果熬底，洋蔥、香味蔬菜）— **客觀程度：高**
- 對應專案欄位：[types/ramen.ts:113-122](types/ramen.ts#L113-L122) `ProteinTagVector`

### 2.2 湯體狀態維度（Broth State）
- **清湯 vs 白湯**（是否乳化）— **客觀程度：極高**
  - 量測方式：濁度計（turbidity meter）、肉眼判別（湯底是否能看見碗底）。
  - 工程學定義：脂肪粒徑與乳化穩定度。
- **熬煮時間帶**（短時清湯 / 長時白湯 / 二度抽 / 替湯）— **客觀程度：高**（製程事實）
- **湯溫與表面油膜厚度**（雞油 / 香味油 / 背脂）— **客觀程度：中高**
- 對應專案欄位：[types/ramen.ts:135-150](types/ramen.ts#L135-L150) `BrothTasteVector.milky`、`IntensityVector.oiliness`

### 2.3 調味基底維度（Tare Type）
- **三大基底**：醬油（shoyu）/ 鹽（shio）/ 味噌（miso）
- **變體**：醬油+鹽、白醬油、黑醬油、田舍味噌、信州味噌、八丁味噌

## 第 3 章 · 既有 4 軸系統的客觀性審查

逐一檢視專案目前的 4 軸（[lib/archetype.ts:18-51](lib/archetype.ts#L18-L51)），評估各軸是「客觀」還是「主觀感受」。

### 3.1 Axis 1 — 濃淡（Richness：C / R）
- **目前定義**：清爽 C(<50) / 濃厚 R(≥50)。加權 = `axis_richness` 75% + `flavor_fatty_sweet` 15% + `topping_backfat` 10%。
- **客觀性審查**：❌ **主要為主觀感受**。雖然可量測「鹽分」「脂肪」「鮮味」等物理量，但「濃淡」混合了脂肪、鹽分、鮮味、口感重量等多重感受，**沒有單一物理對應**。
- **可客觀化路徑**：拆解為三個可儀器量測量：
  - 鹽分 g/L
  - 脂肪含量 g/100mL
  - 胺基酸態氮 mg/100mL（鮮味指標）

### 3.2 Axis 2 — 湯體（Broth Body：K / W）
- **目前定義**：清湯 K / 白湯 W。加權 = `axis_broth_body` 75% + `flavor_fatty_sweet` 10% + `protein_miso` 15%。
- **客觀性審查**：✅ **本質上是客觀的**。「乳化 vs 非乳化」可用濁度計、肉眼判別、或脂肪粒徑分布（雷射粒徑儀）量測。
- **這是 4 軸中最客觀的一軸**。建議保留。

### 3.3 Axis 3 — 衝擊（Impact：L / H）
- **目前定義**：溫和 L / 重口 H。加權 = `axis_impact` 60% + `flavor_spice` 15% + `topping_garlic` 15% + `topping_backfat` 10%。
- **客觀性審查**：❌ **高度主觀**。「衝擊感」是文化建構詞，混合鹹度、辛香、油膩感、香氣濃度，**缺乏單一物理對應**。
- **可客觀化路徑**：拆分為：
  - 鈉含量 mg/100mL
  - 辣度 SHU（若可量）
  - 香料添加 binary
  - 蒜量 g

### 3.4 Axis 4 — 麵體（Noodle Body：F / T）
- **目前定義**：細滑 F / 粗嚼 T。加權 = `axis_noodle_body` 55% + `noodle_thickness` 20% + `noodle_chewiness` 15% + `noodle_firmness` 10%。
- **客觀性審查**：⚠️ **半客觀**。`thickness` 對應實體 mm 是客觀的，但目前是 0–100 主觀刻度；`chewiness`、`firmness` 是觸覺感受，主觀。
- **可客觀化路徑**：切成
  - 麵條直徑 mm 區間
  - 加水率 % 區間
  - 形狀 binary（直 / 縮）
  - 全部可量測。

### 3.5 4 軸客觀性總評

| 軸 | 客觀程度 | 主要問題 | 建議 |
|---|---|---|---|
| Axis 1 濃淡 | 低 | 混合多重感受 | 拆解為「鹽 + 脂 + 胺基酸」三量測量 |
| Axis 2 湯體 | 高 | 已是客觀軸 | 保留；定義為「乳化二元 + 濁度區間」 |
| Axis 3 衝擊 | 低 | 文化建構詞 | 拆解為「鈉 + 辛 + 蒜 + 香料」 |
| Axis 4 麵體 | 中 | thickness/curl 應為實值 | 拆解為「直徑 mm + 加水率 % + 形狀」 |

**結論**：4 軸中只有 1 軸（湯體）真正客觀；其餘 3 軸都依賴主觀感受，正是使用者點出的問題核心。

## 第 4 章 · 不歧義分類的設計原則

回答 Q2 的核心。

### 4.1 為什麼會歧義：三種典型衝突情境
- **衝突一：多重身分**。一碗博多家系豚骨醬油拉麵，同時屬於「博多」（地域）、「家系」（血統）、「豚骨」（食材）、「醬油」（調味）。
- **衝突二：邊界模糊**。雞豚 W 湯（混合），既不是純雞也不是純豚。
- **衝突三：風格變異**。自稱二郎系實為「インスパイア系」，該歸直系還是變體？

### 4.2 解決歧義的三大設計原則

#### 原則 1：階層式優先（Hierarchical Priority）
- **主分類軸**（最高層，唯一互斥）→ **次分類軸**（中層）→ **標籤**（低層，可多重）
- 範例：
  - 主軸 = 主蛋白家族（7 個互斥桶）
  - 次軸 = 乳化狀態（2 桶）
  - 標籤 = 地域 / 血統 / 調味 / 麵規（可多選）

#### 原則 2：必要 / 充分 / 排除條件
為每個流派定義三組條件：
- **必要條件 (Required)**：不滿足就**不可能是**該派（家系必須有「豚骨醬油湯 + 海苔 + 菠菜」）
- **充分條件 (Sufficient)**：滿足就**一定是**該派（拜入吉村家系譜）
- **排除條件 (Exclusionary)**：滿足則**不可能是**該派（無湯 → 不可能是家系）

#### 原則 3：決策樹優於距離度量
- 對於**身分分類** → 用**決策樹**（yes/no 邏輯）→ 結論唯一、可解釋
- 對於**相似度推薦** → 用**距離度量**（向量空間）→ 用於排序
- 目前專案的做法是後者（[lib/scoring.ts](lib/scoring.ts)），**用於推薦合適**；**用於「你屬於哪一派」會歧義**。

### 4.3 兩階段架構建議
- **階段 A — 客觀分類（Identity Classification）**：決策樹，輸出「你的偏好對應哪個流派」，唯一答案、可解釋。
- **階段 B — 偏好評分（Preference Ranking）**：向量距離，輸出「跟你最近的 N 個原型」，排序結果、有 share/score。
- 兩者並存：A 回答「**你是誰**」，B 回答「**你會喜歡誰**」。

## 第 5 章 · MBTI 式 16 型（4 軸二元）在拉麵的可行性

回答 Q1 的第一部分。

### 5.1 MBTI 範式的本質
- 4 個正交二元軸 → 2⁴ = 16 種組合
- 前提：4 軸**獨立（正交）** + 每軸**清楚二元**

### 5.2 拉麵 16 型可行性檢查

#### 正交性檢查 — 失敗
專案目前 4 軸**並非正交**：
- 「濃厚」與「白湯」**高度相關**：白湯通常較濃。例：`tonkotsu_rich` = R+W；`chicken_clear` = C+K。
- 「衝擊」與「濃厚」**高度相關**：濃厚通常較衝擊。二郎 = R+W+H+T，幾乎沿對角線。
- 統計分布上 16 格中**對角線格子高度集中**、**反對角線格子空虛**。

#### 二元性檢查 — 勉強通過

### 5.4 修正版 MBTI（讓 16 型「真的能用」）

#### 方案 A：換成正交的客觀軸

### 6.1 候選方案 A：3×3 九宮格（2 軸三元）— **推薦**

- 拉麵**沒有「動機」**；Enneagram 核心是動機論，直接挪用 = 穿鑿附會。
- 「翼型」（主型 ± 相鄰型）在拉麵上無自然對應。
- 「整合 / 解離方向」無法對應。

**可行性：低**。除非完全重新定義 9 個類型而不沿用 Enneagram 哲學，但那就不是 Enneagram 了。

### 6.3 候選方案 C：其他九分法

## 第 10 章 · 三個問題的最終回答

### Q1. MBTI 式 16 型與 9 型在拉麵上可行嗎？
- **16 型 MBTI**：⚠️ **可行但有侷限**。可作為「偏好風格描述」（第 2 層），不適合作為「身分歸屬分類」。主要問題：4 軸非正交、軸定義仍偏主觀。
- **9 型（3×3 九宮格）**：✅ **高度可行，作為身分分類最佳**。主蛋白 × 湯體乳化提供清晰、客觀、無歧義的 9 格分類（建議擴為 4×3=12 格涵蓋台灣牛系）。
- **9 型（Enneagram-9）**：❌ **不可行**。哲學基礎在拉麵領域無對應，強行套用會失真。

### Q2. 如何做到「不歧義」的客觀分類？
1. **階層式優先架構**：主軸唯一互斥；輔軸與標籤可多重。
2. **必要 / 充分 / 排除三組條件**：為每個流派精確定義。
3. **決策樹處理身分分類、向量距離處理偏好推薦**：兩者分工，不可混淆。

### Q3. 哪些客觀方法可行？
按客觀程度由高到低：
1. **主蛋白來源**（食材清單可考）— 極高
2. **湯體乳化狀態**（濁度可量、目視可辨）— 極高
3. **調味基底**（配方可考）— 極高
4. **麵條規格**（直徑 mm、加水率 %、形狀）— 極高
5. **是否分湯麵 / 是否有湯**（目視即可）— 極高
6. **配料定型組合**（視覺辨識，有 canonical 組合）— 高
7. **地域起源**（店家自稱 + 歷史可考證）— 高
8. **流派血統 / 系譜**（自稱 + 系譜學考證）— 中高
9. **製程時間帶與技法**（可考但取得困難）— 中

**最推薦的客觀組合**：主蛋白（極客觀）+ 乳化狀態（極客觀）+ 流派 / 地域 / 調味標籤（可考證）。
此組合既不歧義、又能完整描述所有 18 個現有原型 + 所有列舉的日本與台灣流派。
